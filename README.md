# AVAL BOT

ربات تلگرام فروش اشتراک VPN با پشتیبانی از:

- چند پنل 3x-ui
- ساخت دسته‌بندی و اتصال هر دسته به inboundهای پنل
- ساخت خودکار کانفیگ هنگام تأیید خرید یا پرداخت از کیف پول
- ساخت خودکار client و ارسال فقط لینک Subscription به‌همراه QR Code
- نمایش لینک‌های اتصال و مصرف/انقضا از پنل
- تست رایگان خودکار از پنل، با fallback به موجودی دستی
- پرداخت کارت‌به‌کارت و کیف پول
- مدیریت کاربران، موجودی دستی، آموزش، ادمین‌ها و بک‌آپ


# ===== نصب مستقیم از GitHub =====

بعد از ساخت Repository عمومی، روی Ubuntu/Debian این دستور را اجرا کن:

```bash
curl -fsSL https://raw.githubusercontent.com/Mahdips/AVAL_Bot/main/install.sh | sudo bash -s -- --repo https://github.com/Mahdips/AVAL_Bot --ref main
```

نصاب از GitHub نسخهٔ branch مشخص‌شده را دانلود می‌کند، سپس Python، وابستگی‌ها و سرویس `systemd` را نصب می‌کند. در اولین اجرا فقط مقادیر ضروری `.env` را به‌صورت مخفی می‌پرسد.

برای آپدیت از همان Repository:

```bash
curl -fsSL https://raw.githubusercontent.com/Mahdips/AVAL_Bot/main/install.sh | sudo bash -s -- --repo https://github.com/Mahdips/AVAL_Bot --ref main --update
```

اگر Repository خصوصی است، این روش بدون احراز هویت کار نمی‌کند؛ برای Repository خصوصی بهتر است ابتدا با SSH/GitHub CLI کلون کنی یا از یک Release/دریافت امن استفاده کنی. هیچ‌وقت `.env`، `bot.db`، Token ربات، API Token پنل یا اطلاعات کارت را در Repository عمومی قرار نده.


برای نصب تکرارشونده روی Ubuntu/Debian، کل پوشهٔ پروژه را روی سرور آپلود کن و فقط این دستور را اجرا کن:

```bash
cd /path/to/AVAL\ BOT
sudo bash install.sh
```

نصاب خودکار Python، محیط مجازی، وابستگی‌ها و سرویس `systemd` را نصب می‌کند، از `.env` و `bot.db` موجود محافظت می‌کند، فقط در اولین نصب اطلاعات ضروری را می‌پرسد و Bot را بعد از ری‌استارت سرور خودکار بالا می‌آورد.

بعد از نصب:

```bash
systemctl status aval-bot
journalctl -u aval-bot -f
```

برای به‌روزرسانی نسخهٔ جدید، فایل‌های پروژه را جایگزین کن و دوباره اجرا کن:

```bash
sudo bash install.sh --update
```

نصاب فعلاً برای Ubuntu/Debian با `apt-get` آماده شده است. اگر Web Panel فقط برای مدیریت شخصی است، `WEB_HOST=127.0.0.1` را نگه دار و از SSH Tunnel استفاده کن؛ پورت 8000 را عمومی نکن.


```bash
python -m pip install -r requirements.txt
copy .env.example .env
python bot.py
```

مقادیر واقعی `BOT_TOKEN`، `ADMIN_IDS`، کارت و سایر تنظیمات را فقط داخل `.env` قرار بده. توکن و API Token پنل را در چت ارسال نکن.

## راه‌اندازی پنل 3x-ui

1. ربات را با یک ادمین اصلی اجرا کن.
2. از پنل ادمین وارد «🌐 مدیریت پنل‌های VPN» شو.
3. «افزودن پنل» را بزن و نام، URL پایه، **لینک Subscription نمونه** و API Token پنل را وارد کن.
4. لینک نمونه باید عمومی و قابل‌دسترسی برای کاربران باشد؛ مثلاً `https://sub.example.com:2096/sub/OLD_TOKEN`. ربات بخش توکن را با `subId` کاربر جایگزین می‌کند. همچنین می‌توانی از قالب `https://domain/sub/{sub_id}` استفاده کنی. برای محصولات پنلی واردکردن این لینک ضروری است.
5. بعد از تست اتصال، یک دسته‌بندی بساز و inboundهای مربوط به آن را انتخاب کن.
6. برای جدا بودن مدیریت، از منوی «🛍 مدیریت محصولات» محصول بساز؛ محصول را فقط به یکی از دسته‌بندی‌های پنلی وصل کن. Inbound دستی برای محصول وجود ندارد.
7. برای تست رایگان، دسته‌بندی و مدت/حجم تست را از بخش تنظیمات تست انتخاب کن.

محصول پنلی هنگام پرداخت از پنل client می‌سازد، زمان آن با حالت **شروع پس از اولین استفاده** تنظیم می‌شود، و فقط لینک Subscription به‌همراه QR برای کاربر ارسال می‌گردد. محصولات دستی همچنان کانفیگ‌های موجودی را ارسال می‌کنند.

در «فهرست پنل‌ها»، با بازکردن هر پنل وضعیت اتصال، CPU، RAM، دیسک، وضعیت و نسخه Xray و تعداد اتصال TCP نمایش داده می‌شود.

## Web Panel مدیریت

Web Panel با همان دیتابیس SQLite ربات ساخته شده و بخش‌های زیر را دارد:

- نمای کلی و آمار کاربران، محصولات، پنل‌ها و سفارش‌های تحویل‌شده
- افزودن، مشاهده، تست اتصال و غیرفعال‌سازی پنل‌های 3x-ui
- نمایش و مدیریت inbound/categoryهای مرتبط با هر پنل
- مشاهده محصولات و غیرفعال‌سازی محصول
- نمایش چیدمان فعلی دکمه‌های Home
- مشاهده کاربران و موجودی آن‌ها
- ورود مدیر با رمز و session cookie امن؛ API Token در صفحه یا گزارش نمایش داده نمی‌شود

برای اجرا، در `.env` مقدار `WEB_ADMIN_PASSWORD` را تنظیم کن. سپس:

```bash
python -m pip install -r requirements.txt
WEB_ONLY=1 python bot.py
```

در ویندوز:

```powershell
$env:WEB_ONLY="1"
python bot.py
```

سپس `http://127.0.0.1:8000/admin` را باز کن. برای دسترسی از اینترنت، Web Panel را پشت HTTPS و reverse proxy قرار بده و رمز ساده استفاده نکن.


تست‌های واحد و smoke test در مسیر `tests/` قرار دارند. تست‌ها نیاز به توکن واقعی ندارند.

```bash
python -m pytest -q tests/test_xui_features.py
python -m py_compile bot.py
```

برای تست واقعی ارتباط با پنل و Telegram، باید `.env` و اطلاعات پنل واقعی تنظیم شوند؛ این مرحله در محیط فعلی اجرا نشده است.
